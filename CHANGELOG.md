# Changelog

All notable changes to **Project Vault** are documented here.

## [1.0.0] - 2026-10-02

### ✨ Added
- **Triple-View Showcase Architecture:**
  - ▦ Launchpad View (Rapid tile scanning with one-click launcher).
  - ◫ Interactive Viewport View (Split-screen live sandbox with Desktop, Tablet, and Mobile device frames).
  - 🎴 Showcase Deck View (Rich cards with 3D hover effects, architecture notes, and modal previews).
- **Cozy & Warm UI Design System:**
  - Warm Dusk, Cozy Espresso, and Deep Forest themes.
  - Glassmorphic card styling, ambient radial glows, and responsive device bezels.
- **Dynamic Project Addition & JSON Export:**
  - Interactive modal with live card preview, category pills, and tag chips.
  - Persistent storage in `localStorage` + exportable `projects.json`.
- **Spotlight Search & Tag Filtering:**
  - Instant search across titles, descriptions, and tags.
  - Multi-category filtering (`All`, `Full-Stack`, `AI / ML`, `Frontend`, `3D / Games`, `Utilities`).
- **Comprehensive QA & DevOps:**
  - Vitest + Testing Library suite with 100% core coverage.
  - Playwright visual regression suite with pixel-by-pixel snapshot comparisons.
  - Husky pre-commit hooks and GitHub Actions CI pipelines.
